## What was blocked (the pretrained translation model)

- Refused by the environment's proxy: `huggingface.co`, `argos-net.com`, `object.pouta.csc.fi`, `zenodo.org`, `translatelocally.com`.
- The Mozilla Firefox Translations English-Spanish model was reachable (storage.googleapis.com) and downloaded with a verified checksum, but its runtime package (`bergamot`) cannot be imported offline (the import fetches a file from `translatelocally.com`); loading the compiled extension directly was not permitted in my environment, so I did not do it.
- Consequence: **no pretrained-translator number exists in this repository.** Nothing from that download is committed.

## Results (from the executed notebook; seed 42, CPU, one run per model; test = 2,000 English sentences)

| Model | BLEU | Exact match | Best validation loss |
|---|---|---|---|
| encoder-decoder LSTM (notebooks 01/02; not re-trained here) | 11.2 | 1.8% | 2.45 |
| attention, random start (re-trained: reproduces notebook 02) | 25.8 | 8.8% | 1.27 |
| attention, GloVe start | 28.9 | 9.8% | 1.18 |

- GloVe minus random start: +3.1 BLEU, 95% paired-bootstrap interval +2.0 to +4.3, ahead in 100% of 200 resamples. By length (1-4 / 5-7 / 8-10 words): +11.2 (159 sentences, noisy) / +2.8 / +2.8.
- Worse than random start for epochs 1-5, ahead from epoch 6.
- GloVe covers 5,991 of 5,996 English vocabulary words (99.99% of the training tokens).
- The random-start model reproduced notebook 02's numbers exactly (same seed, same settings).

## Doubts / open points

- One training run per model; seed variation not measured.
- Only 50 of 128 embedding coordinates start from GloVe; other settings (all coordinates, frozen vectors) were not tried.
- The GloVe licence (PDDL) is taken from the distributing project's listing; I could not open the Stanford page.
- The notebook needs network access to GitHub releases (69 MB download) and takes about 30 minutes of CPU time.
